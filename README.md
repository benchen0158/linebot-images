# linebot-images

LINE bot（linebot-nas）使用的圖庫。

- `images.json`：每一類圖片的檔名格式（`path`，`{:03d}` 代表補零的流水號）與張數（`count`），bot 依這個檔案組出圖片網址，新增圖片後記得更新張數。
- 網址：`https://raw.githubusercontent.com/benchen0158/linebot-images/main/<path>`
